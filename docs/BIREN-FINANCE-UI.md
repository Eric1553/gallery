# 壁仞财务原型的页面设计约束

用户确认于 2026-10-26：原型服务于 FineBI、FineReport 项目落地，应使用容易对应实际报表工程的页面和组件。

- 保留浅色蓝系、既有字体和圆角风格。
- 优先使用普通指标卡、柱状/条形图、折线图、构成图、明细表和常规筛选。
- 使用固定分区和已有页签组织信息；不增加展开收起、嵌套抽屉、悬浮面板等复杂交互。
- 同一指标不重复铺陈；目标、实际、达成率可合并到一张综合指标卡。
- 实际深蓝、预算浅蓝，目标线用虚线；橙红用于风险、逾期和负向缺口。
- 百分比显示保留两位小数，计算精度不变。
- 年度预算、所选期间、时点余额和全周期累计应明确区分。
- 明细表采用结果条数、固定表头、关键列及横向滚动提示；不牺牲字段换取表面简洁。

## v5.1 对应页面

1. CEO：保留五板块，增加普通定位按钮，压缩风险栏，现金及贷款不重复；研发风险灯按95%/100%阈值显示绿/黄/红。
2. 预算：部门、项目和预算科目改横向对比；科目区域加宽，明细独占整行。
3. 销售：一张TOP5客户排行配普通指标选择器；预测用分段构成，收入结构使用条形图。
4. 达成应收：期间达成和时点风险分组；逾期排行合并为金额条及天数表。
5. 个人KPI：订单/收入/回款三张综合卡，保留两张月度趋势，去掉重复仪表盘。
6. 存货：时点指标只出现一次；库存结构、周转跌价、供需预测按固定分区排列，库龄按时间顺序。
7. 研发：科目分析与执行金额并列，部门投入及人力/非人力用紧凑条形图。
8. 填报：四个业务分组、十张业务表；三个预留用一行说明。
9. 明细：保留七个页签，统一表头、列宽、记录数与滚动提示。

说明：本次调整不变更需求评估、人天或底层示例明细。填报及账号仍是原型演示范围。
