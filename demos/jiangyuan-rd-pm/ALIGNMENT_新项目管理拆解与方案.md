## 一、产品实现逻辑（从模板反推）

### 1.1 应用不是「看板网站」，而是表单积木

| 产品对象 | 模板中的落点 | 成员感知 |
|----------|--------------|----------|
| **应用** | 新项目管理 | 左侧目录 + 顶栏待办 |
| **分组** | 统计分析看板 / 客户管理 / 项目启动 / 项目执行 / … | 可折叠文件夹 |
| **普通表单** | 客户、任务管理、基础信息… | 数据管理 + 多视图 |
| **流程表单** | 项目立项、项目计划、任务验收、结项… | 数据管理 +「流程分析」+ 工作台待办 |
| **权限组视图** | 同一张表多条视图 Tab | 表格/看板/WBS/画廊等 |
| **自定义按钮** | 进度更新 / 验收申请 / 变更申请 / 前置依赖 | 行内操作，常跳转辅助流程表单 |
| **仪表盘** | 项目综合看板、员工待办事项… | 指标卡 + 图表 + 甘特组件 + 快捷入口 |
| **智能助手** | （后台）验收→回写任务状态等 | 成员只感知「状态变了」 |

### 1.2 多维度视图的真实挂载点

**挂在「任务管理」表单的权限组视图上**，不是独立模块。实测视图 Tab：

1. 任务WBS分解（树形表格，层级展开/收起）
2. 项目维度任务明细视图
3. 任务负责人负载情况明细
4. 里程碑视图
5. **负责人负载看板视图**（按负责人分列卡片）
6. 任务状态全景图
7. **任务重要紧急程度看板视图**
8. `+ 新建视图`

工具条固定模式：`编辑 | 数据管理 | 新建视图` → `+ 添加 | 导出 | 删除 | 操作记录` → 搜索。

行内自定义按钮（随状态显隐）：`进度更新` / `验收申请` / `变更申请` / `前置依赖`。

### 1.3 关键表单职责链（模板）

```text
客户管理（普通）
    ↓ 选择数据
项目立项（流程：填报 → 审批）——视图：详情 / 画廊 / 看板；有「流程分析」
    ↓ 选择数据 / 助手同步
项目计划（流程）——视图：计划详情（可按状态分组）/ 审批未通过总览
项目预算（普通/流程）
    ↓
任务管理（普通，核心多视图）← 任务进度更新 / 任务验收 / 任务变更（辅助流程）
    ↓
项目结项申请（流程）
仪表盘：项目综合看板（KPI + 任务进度筛选 + 甘特组件 + 快捷入口）
```

辅助表单（任务管理下）：任务进度更新、任务验收、任务变更申请、任务依赖关系-前置/后置。

### 1.4 前端 UI 样式要点（对齐基准）

| 元素 | 样式特征 |
|------|----------|
| 应用侧栏 | 浅灰底 `#f5f6f7` 系；彩色小图标；当前项浅灰圆角底；分组可折叠 |
| 顶区待办 | 「我的待办 / 我发起的 / 我处理的 / 抄送我的」入口 |
| 视图 Tab | 水平 Tab + 青绿下划线（约 `#00b899`）；右侧 `+` |
| 主按钮 | 青绿实心 `+ 添加` |
| 状态徽章 | 圆角 pill：进行中橄榄/橙、已验收蓝、已完成绿、未开始橙、已取消红 |
| 任务类型徽章 | 里程碑粉、子任务青绿 |
| 看板卡片 | 白底圆角卡片；字段带小图标；底栏「进度更新」描边按钮 |
| 表格 | 白底、细分隔线、可选中、树形缩进 + 展开箭头 |
| 仪表盘 | 深蓝横幅标题 + 快捷入口图标行 + KPI 色条卡片 + 饼/柱 + 甘特明细 |

## 三、江原 DEMO 重构方案（成员前台）

### 3.1 应用目录（映射模板分组，替换江原对象）

```text
江原研发项目管理
├── ⭐ 员工待办事项（仪表盘/待办聚合示意）
├── ⭐ 项目总览（可做项目主档入口或仪表盘）
├── 统计分析看板
│     ├── 多项目概览（对标项目综合看板）
│     └── Signoff 统计
├── 主数据维护
│     ├── 项目类型 / 阶段模板 / 费用科目 / Domain / Signoff检查项模板
├── 项目启动
│     ├── 项目立项（流程）
│     ├── 项目计划 / 里程碑（流程或普通+审批）
│     └── 项目预算
├── 项目执行
│     ├── 任务管理 ★多视图（WBS表格 / 看板×N / 里程碑 / 甘特或状态全景）
│     ├── 任务进度更新 / 任务验收 / Exit Review（辅助流程）
│     ├── Signoff 检查条目
│     ├── 问题风险 / DACI
│     └── 项目公告与链接
├── 项目结项
│     ├── 结项申请 / 中止申请（流程）
└── （可选弱入口）使用说明
```

> 模板中的客户/合同/回款：江原 DEMO **不做或仅预留隐藏分组**，避免偏离研发场景。

### 3.2 「任务管理」多视图（客户强调点 — 按产品方式做）

同一数据源 `任务/里程碑计划`（字段用江原：路径/技术方向、阶段、计划起止、完成状态、关键、Exit 类型…）：

| 视图名（建议） | 类型 | 分组/结构 | 对标模板 |
|----------------|------|-----------|----------|
| 任务WBS分解 | 树表 | 项目→阶段→任务层级 | 任务WBS分解 |
| 里程碑视图 | 表格/筛选 | 仅关键里程碑 | 里程碑视图 |
| 负责人负载看板 | 看板 | 分组=负责人 | 负责人负载看板视图 |
| 任务状态看板 | 看板 | 分组=完成状态 | 任务状态全景/状态看板 |
| 甘特进度 | 甘特 | 开始/结束/进度 | 综合看板甘特 + 表单甘特视图 |
| （可选）重要紧急看板 | 看板 | 优先级×状态 | 重要紧急程度看板 |

行内按钮（演示级，跳转抽屉即「辅助流程表单」）：

- 进行中 → `进度更新`
- 可验收 → `验收申请` / `Exit Review`
- 计划变更 → `变更申请`

### 3.3 主业务闭环（验收剧本）

1. 打开「项目立项」→ 画廊/看板浏览 → 发起立项（流程待办示意）→ 通过后主档「执行中」  
2. 「项目计划」维护阶段/里程碑  
3. 「任务管理」用 **WBS Tab** 看结构 → **负责人看板** 拖拽/改状态 → **甘特** 看工期  
4. 行内「进度更新」「验收」走辅助流程  
5. 「Signoff」Owner/Approver  
6. 「多项目概览」仪表盘下钻回表单  

### 3.4 技术实现约定（HTML DEMO）

- 路由心智：`/app` → `/form/:id?view=` → `/dash/:id` → `/todo`  
- CSS token：浅侧栏、青绿主色、pill 徽章、视图 Tab 下划线、卡片看板  
- 数据层保持「表单记录」模型（每条有 `_id`、字段 map），视图只是投影  
- **不**再做成深色自定义工作台壳  

### 3.5 分期

| 期 | 交付 | 对齐重点 |
|----|------|----------|
| P0 | 应用壳 + 待办条 + 表单页框架（Tab 视图） | UI 一眼像简道云 |
| P1 | 任务管理 4～5 视图 + 行内按钮 | 多维度核心 |
| P2 | 立项/计划流程感 + 项目清单 | 闭环 |
| P3 | Signoff + 多项目仪表盘 | 江原差异化 |
