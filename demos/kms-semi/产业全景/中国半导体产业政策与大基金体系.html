中国半导体产业政策与大基金体系

政策逻辑

中国半导体产业政策的核心逻辑经历了三个阶段：

  1. 2014-2019（补短板）：认识到差距，用国家资本启动追赶
  2. 2019-2024（攻关键）：聚焦设备、材料、EDA等卡脖子环节
  3. 2024-2030（建体系）：在出口管制全面升级的背景下，建立一个完全自主的半导体产业体系

这一逻辑转变与美国的出口管制升级高度同步——2022年10月的BIS规则是分水岭，此后"自主可控"从口号变成了生存刚需。

大基金体系

国家集成电路产业投资基金（简称"大基金"）是中国半导体产业政策中最核心的金融工具。

大基金一期（2014-2019年投资期，2019-2024年回收期）

  • 总规模：1,387亿人民币（其中国家出资约360亿，其余来自金融机构和央企）
  • 资金分配：
  • 芯片制造：约65%（中芯国际、长江存储、华虹等）
  • IC设计：约17%
  • 封测：约10%
  • 设备材料：约8%

一期的思路是"以制造带动全局"——先确保有Fab能生产芯片，再逐步向上游设备和材料延伸。

大基金二期（2019-2024年投资期）

  • 总规模：2,041亿人民币（社会资本参与度更高）
  • 资金分配明显调整：
  • 设备材料占比提升至20%以上（北方华创、中微公司、沪硅产业等）
  • 更多投向"卡脖子"环节

二期的思路转变为"重点突破设备和材料"。

大基金三期（2024年起）

  • 总规模：3,440亿人民币（单期规模超过前两期之和）
  • 出资方：财政部 + 国开金融 + 六大国有银行 + 地方国资

三期投向的重大变化： 1. AI芯片：国产GPU/NPU成为最优先级（华为昇腾、寒武纪等） 2. 先进制造设备：光刻机、离子注入机等"卡脖子"设备 3. 先进封装：CoWoS等同路线的国产化 4. EDA工具和IP：全流程EDA的自主攻关 5. 第三代半导体：SiC（碳化硅）、GaN（氮化镓）材料和器件 6. HBM（高带宽内存）：AI芯片配套的存储堆叠技术

三期的运作思路也更加市场化：引入专业投资管理人、强调投资回报率、允许适度的退出机制。

财税优惠政策

企业所得税

集成电路企业享受阶梯式税收优惠，与制程节点挂钩：

制程节点 优惠
≤28nm（经营期15年以上） 十年免征所得税
≤65nm（经营期15年以上） 五免五减半
≤130nm（经营期10年以上） 两免三减半

人才政策

  • 上海临港新片区：集成电路高端人才个人所得税15%封顶
  • 多地提供购房补贴、子女入学等配套政策

政策效果评估

已经见效的领域

  • 封测：长电科技已是全球前三，技术水平与国际头部差距最小
  • 成熟制程设备：北方华创、中微公司、盛美的产品已在成熟产线上批量应用
  • IC设计：海思在手机AP/基带、寒武纪在AI推理芯片方面有实际竞争力

仍然困难的领域

  • 光刻机：真正的"皇冠明珠"，差距可能在10-20年
  • EDA全流程：点工具可替代，全流程仍遥遥无期
  • 先进制程制造：14nm以下在出口管制放松之前几乎无解

💼 售前场景

场景1：用大基金话题判断客户预算充裕度

使用方式：这篇笔记是售前判断半导体客户IT预算能力的"财务晴雨表"。在初次拜访中自然提及大基金信息，根据客户反应判断其资金状况。

售前话术模板：

"大基金三期3440亿，六大重点投向里有一个是先进封装——你们正好在这个赛道上。这轮资金到位后，扩产会带来设备、人员和数据系统的新增需求。我们的方案可以在扩产初期就植入数据架构，避免扩产后数据系统补丁摞补丁。"

判断客户资金能力的三层信号： 1. 绿灯客户：客户主动提及大基金投了他们/他们正在申报大基金项目 → 预算充裕，重点推进 2. 黄灯客户：客户知道大基金但未直接受益，在"产业集群"区域内 → 有一定预算，正常跟进 3. 红灯客户：客户不在大基金关注领域且不在主要产业集群 → 预算受限，确认后再投入

场景2：针对地方产业集群的园区项目

客户画像：上海临港/合肥高新区/武汉光谷等半导体产业园区的管委会或平台公司，需要向地方政府汇报产业集群发展情况。

售前切入点： - "你们园区有30家半导体企业——市领导来视察时，你们能一块大屏展示'园区半导体产值、企业数量、税收贡献、就业人数、国产替代贡献度'吗？FineReport的大屏让园区从'一张嘴汇报'变成'一屏展示'。" - 核心方案：FineReport产业大屏 + FDL对接园区统计系统 + FineBI产业集群对标分析

场景3：财税政策类信息的售前价值

使用方式：半导体企业的税收优惠政策（≤28nm十年免税等）是精准评估客户盈利能力和IT预算的重要线索。

售前应用： - 如果客户Fab的制程节点≤28nm → 享受"十年免所得税"，净利润率远高于不享受优惠的企业 → IT预算空间更大 - 如果客户是65nm-130nm区间 → 享受"五免五减半" → 仍有政策红利但不如28nm以下充裕 - 话术："你们28nm产线享受十年免所得税——这部分省下来的钱，投入在良率管理和数据分析上，能让先进制程的良率爬坡快三个月，ROI远超系统投入。"
