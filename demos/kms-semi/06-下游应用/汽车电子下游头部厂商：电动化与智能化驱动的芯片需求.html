汽车电子下游头部厂商：电动化与智能化驱动的芯片需求

从芯片采购视角梳理汽车电子下游三大势力——整车厂、Tier1供应商、自动驾驶公司——的芯片战略与采购特征，为帆软售前团队识别潜在客户画像与切入场景。

一、全球新能源汽车整车格局与芯片战略

1.1 Tesla：自研芯片的终极玩家

Tesla 是全球最早也是最坚决走芯片自研路线的主机厂。

  • FSD芯片：2019年量产，由三星14nm代工，算力144 TOPS（双芯片冗余架构）。Tesla 从Mobileye（2014-2016）→ NVIDIA（2016-2019）→ 自研FSD，核心驱动是对"软硬一体"极致效率的追求。FSD芯片专为Tesla的BEV+Transformer算法优化，通用GPU跑同样的算法效率远不及专用ASIC。
  • Dojo超算：Tesla自研训练芯片D1，7nm工艺，用于训练自动驾驶模型。Dojo不是卖给别人的产品，而是Tesla内部"算力军备竞赛"的基础设施——2025年Dojo总算力达到100 Exa-FLOPS级别。
  • 供应链特征：Tesla拥有强大的内部芯片设计团队（由前AMD/Apple芯片架构师领导），但其芯片不是IDM模式——设计自己做，制造外包给三星/台积电。Tesla的芯片采购更像一家Fabless公司，需要管理IP授权、流片、封装、测试等完整供应链。

芯片自研路径总结：Mobileye（外部黑盒）→ NVIDIA（外部开放平台）→ 自研（完全掌控）。这是整车厂智能化竞争的终极形态。

1.2 BYD：功率半导体的垂直整合之王

  • 比亚迪半导体的详细分析见比亚迪半导体：车规级功率器件的垂直整合样本。
  • 在外购芯片方面，BYD的主要采购集中在：智能驾驶SoC（地平线征程5/征程6 → 用于DiPilot智驾系统）、座舱SoC（高通Snapdragon）、MCU（部分外购NXP/Infineon补充）。
  • 战略要点：BYD的芯片策略是"功率器件自研以控成本、智驾芯片外购以求最优"——这是最务实的混合路线。

1.3 蔚来、小鹏、理想：NVIDIA阵营的三驾马车

中国新势力三强在智驾芯片上的选择高度趋同——NVIDIA Orin → Thor 演进路线：

车企 智驾芯片 配置 智驾系统
蔚来 4×Orin-X (1016 TOPS) 全系标配 NIO Adam超算平台
小鹏 2×Orin-X (508 TOPS) 高配车型 XNGP全场景智驾
理想 2×Orin-X (Pro) / 地平线征程5 (Air) 分档配置 AD Pro / AD Max

芯片采购特征： - 三家都深度依赖NVIDIA Orin平台，正在向Thor迁移（Thor单芯片2000 TOPS，可一芯多用替代多颗Orin） - 同时保持对国产芯片的开放态度——理想Pro版用征程5就是样板，未来可能扩展到地平线征程6 - 座舱芯片以高通Snapdragon为主（8155 → 8295 升级路线） - 三家的芯片采购部门比传统车企更接近消费电子公司的运作方式——快速迭代、多供应商策略、关注BOM成本

1.4 小米汽车：消费电子基因的降维打击

  • 小米SU7搭载2×NVIDIA Orin-X + 高通8295座舱芯片
  • 小米的芯片采购特征独特：复用手机供应链关系——小米在手机SoC（高通）、Memory、Sensor领域有十多年的采购量和议价能力，汽车芯片采购可以部分继承这些供应商关系
  • 长期看点：小米旗下有自研芯片历史（澎湃系列），不排除未来自研智驾芯片的可能性

1.5 大众、丰田、现代起亚：传统巨头的转型博弈

  • 大众：软件子公司CARIAD负责智驾自研，与高通合作Snapdragon Ride平台，同时投资地平线（2022年大众与地平线成立合资公司酷睿程，大众持股60%）
  • 丰田：保守策略，ADAS以Mobileye EyeQ为主，高端智驾与NVIDIA合作。丰田的芯片采购特点是"求稳不求新"——优先选择有10年以上量产经验的芯片
  • 现代起亚：Mobileye + NVIDIA双路线，韩系车在全球ADAS芯片采购上偏Mobileye（成本优势），高端车型导入NVIDIA

传统车企芯片采购共同特征： - 决策链条长（需通过Tier1间接采购） - 芯片选型优先AEC-Q100认证和长期供应承诺 - 对国产芯片接受度低，但在地缘政治压力下开始关注中国替代方案

二、Tier1供应商：芯片流向整车厂的必经之路

Tier1是汽车芯片的最大买家和集成商——整车厂通常不直接从芯片原厂采购，而是由Tier1购买芯片并集成为ECU/域控制器交付。

2.1 博世（Bosch）：全球最大汽车Tier1

  • 芯片采购特征：博世是全球最大的汽车半导体买家之一，年芯片采购额超百亿欧元
  • 自研芯片：博世在德累斯顿拥有12寸晶圆厂，自产MEMS传感器和ASIC，2025年切入SiC生产
  • MCU策略：博世广泛采购Renesas/NXP/Infineon/TI的MCU，且对国产MCU（芯驰、杰发）持开放态度（通过中国本地团队评估）
  • 数据化现状：博世全球拥有数百个工厂和研发中心，MES/ERP多系统并存，数据整合需求巨大

2.2 大陆集团（Continental）

  • 与地平线成立合资公司"大陆芯智驾"，整合征程系列芯片到大陆的ADAS域控制器中
  • 传统强项是制动/底盘电子（ESC、EPB），芯片以MCU+传感器为主

2.3 电装（Denso）：丰田系的芯片管家

  • 丰田持股，深度绑定丰田供应链
  • 自研MCU和功率器件能力，同时在Renesas（丰田/电装/瑞萨三者有交叉持股关系）采购大量芯片

2.4 采埃孚（ZF）

  • 2023年推出基于地平线征程5的ADAS域控制器产品线
  • 采埃孚的传统强项是变速箱和底盘，智能化转型依赖外部芯片平台

2.5 安波福（Aptiv）

  • 从德尔福分拆，专注汽车电子电气架构
  • 与Mobileye深度合作开发L4自动驾驶平台
  • 安波福的采购特点是"全栈集成"——不仅买芯片，还买算法和系统方案

2.6 华为车BU：中国Tier1的新物种

  • 华为车BU不是传统Tier1，而是一个"Tier0.5"角色——比Tier1更深入整车定义
  • MDC计算平台（Mobile Data Center）：基于昇腾AI芯片，覆盖L2到L4。MDC 610（200 TOPS）、MDC 810（400+ TOPS）
  • 鸿蒙座舱平台：基于麒麟芯片
  • 华为车BU的芯片全部来自海思，海思是华为的全资芯片设计公司（详见华为海思_HiSilicon_深度企业档案），受美国制裁限制，但华为通过存量芯片+国内代工渠道维持供应
  • 芯片采购特征：华为车BU不对外采购核心计算芯片——它是海思的"内部客户"。这种自闭环模式使华为在芯片供应链上有独特韧性

Tier1的核心矛盾：传统Tier1靠卖ECU赚钱（一个ECU = 一颗MCU + 软件 + 外壳 + 线束），利润丰厚。但集中式架构下ECU数量从100+降到10-20，Tier1的角色从"ECU供应商"变为"域控制器集成商"——硬件价值下降，软件价值上升。这直接改变了Tier1的芯片采购结构：MCU需求下降，SoC需求上升。

三、自动驾驶公司：芯片需求的新物种

3.1 Waymo（Alphabet旗下）

  • 全球自动驾驶技术最领先的公司，2025年在旧金山、凤凰城、洛杉矶运营Robotaxi商业服务
  • 芯片策略：Waymo历史上使用自研TPU（与Google共享）进行感知和规划计算。2025年起与NVIDIA合作导入Orin/Thor，但仍保留自研推理芯片能力
  • 对芯片行业的影响：Waymo的Robotaxi车队规模如果从数千扩展到数万，将是车载高性能计算芯片的巨大增量市场

3.2 Cruise（GM旗下）

  • 2024年后战略收缩，暂停Robotaxi运营，重心转向个人车主L2+智驾（与GM车型整合）
  • 芯片依赖外部采购（NVIDIA为主），不像Waymo有自研能力

3.3 Mobileye（Intel旗下）

  • EyeQ系列是ADAS芯片历史出货量第一（累计超1.5亿颗）。详见汽车半导体行业全景中的分析
  • Mobileye的EyeQ6（2025年量产，7nm工艺）算力约150 TOPS
  • "黑盒模式"困境：Mobileye将芯片+感知算法+驾驶策略打包出售，车企无法修改任何算法逻辑。这种模式在新势力车企中越来越不受欢迎——但它们同时也在大量采购Mobileye（尤其是全球传统OEM市场）

3.4 百度Apollo

  • 中国自动驾驶技术积累最深的企业，Robotaxi平台"萝卜快跑"在中国多城市运营
  • 芯片策略：Apollo的计算平台使用NVIDIA和国产芯片（地平线/黑芝麻）的混合方案，不做自研芯片（百度昆仑芯片用于云端训练而非车载）
  • Apollo的商业模式是向车企输出智驾方案（ANP领航辅助驾驶），其芯片采购由合作的Tier1或车企承担

3.5 小马智行（Pony.ai）

  • 中国头部自动驾驶独角兽，2024年美股上市
  • 在中国与丰田合作推进Robotaxi
  • 芯片采购以NVIDIA为主，未自研芯片

自动驾驶公司的芯片采购特征：对芯片的第一要求不是成本，而是算力+能效比+软件生态成熟度。NVIDIA CUDA生态在这一领域几乎不可替代——即使有参数相当的国产芯片，算法迁移成本也极高。这是NVIDIA在车载高性能计算领域护城河最深的原因。

四、从"芯片采购视角"看汽车电子下游

4.1 汽车电子的芯片采购三层结构

层级 角色 芯片采购特征 年采购规模（估算）
整车厂 终端需求方 通过Tier1间接采购，头部OEM开始直接与芯片原厂签长约 数十亿-百亿美元（含通过Tier1）
Tier1 芯片集成商 芯片最大直接买家，从原厂采购并集成为ECU/域控 博世单家超百亿欧元
自动驾驶公司 算法公司 采购高算力SoC自用（Robotaxi）或向车企/Tier1推荐芯片平台 数千万-数亿美元

4.2 对芯片原厂而言，谁是真正的"客户"？

传统模式下Tier1是芯片原厂的直接客户，但集中式架构正在瓦解这一模式——整车厂（特别是新势力）越来越倾向直接与芯片公司建立深度合作关系，跳过Tier1进行芯片选型和软件适配，Tier1的角色退化为硬件集成和代工制造。这直接改变芯片公司的销售策略——从"搞定Tier1的采购部门"变为"搞定整车厂的EE架构部门和智驾VP"。

4.3 对帆软售前的启示

汽车电子下游（整车厂+Tier1+自动驾驶公司）有三类不同的数据化需求，对应不同的帆软产品切入路径：

客户类型 典型客户 数据化痛点 帆软切入
整车厂（新势力） 蔚来/小鹏/理想/小米 车型项目进度管理、供应链可视化（含芯片供应风险）、智驾数据闭环 FineReport项目看板 + FineBI经营分析
整车厂（传统） 大众/丰田/比亚迪 多工厂/多品牌经营分析、供应链协同、质量追溯 FDL多源数据集成 + FineReport管理驾驶舱
Tier1 博世/大陆/华为车BU 多客户多项目管理、全球供应链可视化、研发效能 FineBI研发效能 + FineReport全球经营看板
自动驾驶公司 Waymo/百度Apollo/小马智行 Robotaxi运营数据、路测数据分析、算法迭代追踪 FineBI运营分析 + FDL路测数据对接

💼 帆软关联度分析

产品线 关联度 说明
数据分析 (FineReport/FineBI) 🟢高 整车厂经营分析、Tier1项目管理与供应链看板、自动驾驶运营分析——汽车电子下游是帆软数据分析产品的天然适配场景
数据底座 (FDL/数仓) 🟡中 整车厂多系统（PLM/MES/ERP/CRM）数据汇聚，Tier1多工厂数据整合，FDL有明确落地场景但通常需与客户现有数仓策略对齐
AI (Agent/智能问数) 🟡中 供应链风险预警（芯片短缺预测）、智能问数（管理层自然语言查询车型销量/项目进度），场景明确但汽车行业AI落地偏保守
零代码/应用 (简道云类) 🟡中 试制车间管理、测试车辆调度、零部件样件追踪等非核心流程，Tier1的工装/检具管理——场景多但多为长尾需求

🎯 售前场景

  1. 见新势力车企客户时："你们的车型从立项到SOP要3年，中间几十个里程碑节点——FineReport把项目进度、资源占用、风险预警拉到一张看板上，PMO不用追着人问进度"
  2. 见Tier1客户时："你们同时供应几十家整车厂，每个客户的项目周期和交付要求都不一样——FineBI帮你们按客户/项目/产品线分析毛利率、交付准时率、研发投入占比"
  3. 见传统车企客户时："你们有几十个工厂和几百家供应商，数据散在SAP/西门子/自研系统里——FDL先把数据拉通，FineReport再做管理驾驶舱，让集团领导一眼看清各基地的经营状况"
  4. 见自动驾驶公司时："你们的Robotaxi每辆车每天产生TB级路测数据——FineBI对接路测数据库，做接管率趋势、ODD覆盖度、场景分布的多维分析"

⚠️ 注意事项：汽车电子下游客户（特别是整车厂和大型Tier1）的数据化预算通常远高于半导体行业客户，但决策链更长、竞争更激烈（SAP/Tableau/Power BI/国产BI多线竞争）。售前策略应以"懂行业+快落地"为差异化——展示对汽车电子产业链的理解比展示产品功能更能建立信任。
