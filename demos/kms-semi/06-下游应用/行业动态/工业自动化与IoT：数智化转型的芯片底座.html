工业自动化与IoT：数智化转型的芯片底座

📌 一句话摘要

工业自动化与IoT是半导体下游最大的"长尾金矿"——不像手机和PC那样高度集中，而是由数百家头部厂商构成的分散采购体系。每一台PLC、每一个机器人关节、每一块智能电表背后，都是MCU、通信芯片、功率器件和IoT SoC的刚性需求。

🔑 一、工业自动化：PLC、DCS与运动控制的半导体需求

工业自动化是半导体下游最稳定的基本盘之一。全球工业自动化市场约2500亿美元，年增速4-6%，核心竞争壁垒不在硬件本身，而在行业Know-how（工艺理解）+ 生态绑定（编程环境/协议栈）。

工业自动化的芯片采购全景

  • MCU/MPU：每台PLC至少1颗主控MCU（通常ARM Cortex-M4/M7或Cortex-A系列）；大型PLC用多颗MCU+FPGA协同。TI Sitara（AM335x/AM62x）、ST STM32、NXP i.MX RT系列是主流。
  • 工业通信芯片：PROFINET/EtherCAT/EtherNet/IP/PowerLink等工业以太网协议需要专用ASIC或FPGA实现。TI的Sitara系列内置PRU-ICSS（可编程实时单元）支持多协议是一大卖点。
  • 隔离与接口：工业现场电压高、噪声大——每路I/O都需要隔离（光耦或数字隔离器）。ADI和TI的隔离器芯片是隐性刚需。
  • 功率器件：变频器和伺服驱动器内是IGBT模块和IPM（智能功率模块）的核心战场。Infineon占据全球IGBT约30%份额。

🔑 二、工业机器人：关节里的芯片战争

全球工业机器人年装机量约55万台，中国市场占51%。机器人控制器、伺服驱动器、示教器三大核心部件均高度依赖芯片。

🔑 三、IoT平台与智能家居：百亿颗芯片的消耗场

IoT是半导体出货量最大的下游应用——全球IoT连接数已超180亿，中国贡献约40%。与工业自动化不同，IoT芯片的核心逻辑是低成本、低功耗、海量出货。

智能家居的芯片消费结构

注：芯片设计侧详见 04-IC设计/行业动态/IoT-WiFi-蓝牙芯片：乐鑫、泰凌微、恒玄与中国IoT芯片生态，此处聚焦平台采购视角。

  • WiFi/BLE SoC：这是IoT最大宗的芯片品类。每台智能灯、智能插座、传感器都需要一颗。乐鑫（ESP32系列）和Realtek（Ameba系列）是全球出货量前二；泰凌微在BLE细分有优势。联发科（MediaTek）在高端智能电视、智慧屏SoC市场主导。
  • 恒玄：TWS耳机蓝牙音频SoC龙头，不直接参与智能家居主控竞争，但受益于手机厂商IoT生态中的可穿戴设备放量。
  • MCU：不带无线连接的低功耗MCU（如ST STM8/STM32）仍在大量家电中用于电机控制、面板显示。

🔑 四、能源与电力：功率半导体的超级赛道

能源转型是功率器件最大的需求驱动——光伏逆变器、储能变流器、充电桩、柔性直流输电——每个环节都是IGBT、SiC MOSFET和高压功率器件的消耗大户。

厂商 领域 2025年营收 芯片采购规模（估） 采购重点
阳光电源 光伏逆变器全球第一 ~¥800亿 功率半导体采购超¥60亿 IGBT模块（Infineon为主，斯达半导/士兰微国产替代加速中）
宁德时代 动力电池+储能系统 ~¥4500亿 芯片采购超¥100亿（含BMS AFE/隔离/MCU） BMS模拟前端（ADI/TI）、隔离器、MCU；功率器件在Pack和储能变流器中用量大
国家电网 电力传输与配网 — 芯片采购超¥200亿（含智能电表/继电保护/特高压） 智能电表用MCU（瑞萨/ST）+ 计量SoC（ADI/钜泉光电）；特高压换流阀用晶闸管/IGBT；南瑞、智芯微（国网自研芯片子公司）有大量"自主可控"采购需求
南方电网 南方五省电力传输 — 芯片采购约¥80-100亿 与国家电网类似，但体量较小；同样有"自主可控"政策要求

能源赛道的器件结构

  • IGBT：光伏逆变器和储能变流器的绝对主力。阳光电源全球逆变器出货量超100GW，每GW约消耗2000-3000颗IGBT模块。Infineon、ON Semi、斯达半导、士兰微是主要供应商。
  • SiC MOSFET：2026年开始加速渗透——阳光电源、华为数字能源的高端逆变器已批量导入SiC，体积缩小30%、效率提升1-2%。Wolfspeed、ST、ROHM先行，中国天科合达（衬底）和瞻芯电子（器件）在追赶。
  • BMS芯片：每辆电动车和每个储能柜都需要BMS。ADI（LTC系列）和TI（BQ系列）占据BMS模拟前端90%以上份额——这是当前国产替代最难攻克的模拟芯片高地之一。

零代码/应用 (简道云类) 🟡中 工业自动化企业的非核心流程场景与设备商类似：备件管理、巡检工单、售后报修、展会线索收集。机器人厂商的售后工程师在全国巡检——简道云的移动端填报+拍照上传是非常好的轻量化工具。

🎯 售前场景

场景一：工业自动化厂商（汇川技术/中控技术类）

客户画像：百亿营收制造企业，SAP+自研MES+PLM，IT团队50-200人，数据需求从"领导要看报表"进化到"要建数据底座"。 切入路径： 1. FineReport → 经营分析会看板、"董事长一张表"（参考北方华创200W案例） 2. FineBI → 供应链控制塔、渠道进销存分析、售后故障Pareto 3. FDL → SAP+MES+SRM数据打通（"解决Excel飞来飞去的痛点"） 4. AI Agent → 智能问数（管理层直接问"上月伺服出货多少"）

竞品注意：工业自动化厂商通常已有SAP BO/Oracle BI/Tableau中的至少一种。帆软差异点：① 国产化/信创合规（FineReport完全自主可控）；② 报表格式精确控制能力远超Tableau；③ 本地化服务。

场景二：能源电力企业（阳光电源/宁德时代/国家电网类）

客户画像：营收数百亿至千亿，华为/阿里云已深度渗透（阿里云DataWorks+Quick BI在国家电网体系有大量部署），信创"自主可控"是硬约束。 切入路径： 1. FDL → 围绕信创需求，FDL做"国产ETL替代Informatica/Kettle"的定位 2. FineBI → 供应链分析（宁德时代的上游锂/钴/镍采购成本波动极大，BI多维分析有刚需） 3. FineReport → 国资委/证监会合规报表（年报附注表、ESG报告）→ 这是FineReport的传统强项

竞品注意：阿里云Quick BI在国家电网/南方电网体系渗透极深。帆软优势：① "离线部署"能力（很多电力场景不能上公有云）；② 复杂报表（国网需要上百张固定格式的调度报表，FineReport比Quick BI更精准）；③ 华为MetaERP项目后，华为体系客户对国产BI的接受度提高。

场景三：IoT平台和智能家居厂商

客户画像：小米/美的/海尔——IT建设水平极高，通常自研数据中台，对第三方BI需求较弱。但他们的上游供应商和下游经销商是帆软的机会： - 小米生态链企业（数百家中小制造企业）→ 它们是典型的"有数据但没分析能力"的离散制造商 - 海尔/美的的经销商体系 → 进销存报表、返利核算 - 涂鸦智能的客户（全球中小IoT品牌商）→ 它们需要的是设备运维+售后分析，而非IoT平台本身

竞合关系：小米/阿里云/华为本身有数据产品（小米有自研BI、阿里有Quick BI、华为有GaussDB+DataArts），不是帆软目标客户。但它们的产业链上下游企业是。
