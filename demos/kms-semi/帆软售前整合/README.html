🧭 使用指南

  1. 定行业 → 打开对应桥接页（帆软售前整合/半导体设备 / 帆软售前整合/晶圆制造 / 帆软售前整合/封装测试 / 帆软售前整合/IC设计）
  2. 定产品 → 打开 帆软售前整合/产品线速查矩阵，确认该行业该产品的最佳切入场景
  3. 查话术 → 打开 帆软售前引擎/话术方案/售前话术与方案库，准备角色话术和质疑应对

  5. 刷动态 → 桥接页底部「近期动态」了解客户所在领域的最新变化
