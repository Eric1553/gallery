🏭 行业画像

半导体设备是半导体产业链的"卖铲人"——芯片厂可以不赚钱，设备商一定赚钱。一台 EUV 光刻机售价超 3 亿欧元，设备投资占晶圆厂总投资的 80%。

设备商典型特征： - 项目制收入、财务里程碑敏感 - CRM/ERP/服务系统分立，管理层要"一张健康度视图" - 全球多法人、多币种、多语言 - 设备昂贵，OEE（综合效率）和预测性维护是核心关注

🟢 核心方案

1. 帆软售前引擎/数据分析场景/半导体设备-四产品场景方案

知识点 帆软产品 售前场景描述
设备商管理层要"健康度视图"（漏斗在CRM、里程碑在ERP、工单在服务） FineBI + FDL 跨系统经营驾驶舱：FDL 打通 CRM/ERP/服务系统，FineBI 构建销售-PMO-服务-CFO 四角色看板。售前话术："你们的老板每周一看三张 Excel，我们让这三个系统的数据自动住到一张 BI 看板上"
总部固定模板（全球统一格式、参数化、可审计） FineReport 参数化模板门户：FineReport 参数化+版本页脚+调度推送，区域用户选择参数后自动生成 PDF。售前话术："亚太区填亚太的，欧洲区填欧洲的，总部一键汇总，格式绝对统一"
Pipeline 对不上财务/ERP FDL + FineBI 阶段/金额对账：FDL 做 CRM 阶段与 ERP 里程碑映射，FineBI 对账视图 + FineReport 定稿。售前场景：销售说签了 5000 万，财务说只看到 2000 万——哪个阶段的数据断了？
装机延误扯皮（里程碑事件非结构化） FineBI + 简道云 事件时间线归因：简道云补录现场里程碑事件 → FineBI 时间线分析 → FineReport 客户周报。售前话术："装机延误是客户的场地没准备好，还是你们的工程师没到位？FineBI 帮你们把每一笔延误归到根因"
SLA 超标（工单优先级混乱、客户原因未剔除） FineBI + FineReport 工单结构分析：FineBI Pareto 分析（哪些客户/机型 SLA 超标最严重），FineReport 月报定稿。售前追问："你们的 SLA 计算有没有剔除客户原因导致的等待？"
备件急单接不住 FineBI 机型-BOM 前置分析：FineBI 按机型做 BOM 级库存预警，在紧急订单发生前预测备件需求
不让直连 ERP FineDataLink 只读副本架构：FDL 定时同步 ERP 到只读副本，不碰生产系统。售前话术："我们不碰生产系统，FDL 只读副本，ERP 该怎么跑还怎么跑"
审计导出（合规+留痕） FineReport 水印+权限+审计日志：FineReport PDF 水印输出，权限分级，满足 SOX/ISO 合规
FSE 工时分散（现场工程师用 Excel 邮件） 简道云 + FDL 移动端工时填报：简道云移动端打卡填工时 → FDL 汇聚到 HR/项目系统
续费到期没人跟 FineReport + FineBI 合同维表 + 到期推送：FineReport 定时推送续费预警，FineBI 续费率分析

3. 03-半导体设备/行业动态/长江存储（YMTC）：Xtacking架构与3D NAND的自主之路

知识点 帆软产品 售前场景描述
Xtacking 架构：存储阵列与外围 CMOS 分开制造再键合 → 相当于两个"晶圆厂"并联 FineReport + FineBI 多工艺路线生产管理：设备商面对"两片晶圆分开加工再组装"的新模式，报表需要区分 Array 线和 CMOS 线的 WIP/良率/设备 OEE。FineReport 做双线 FAB 生产报表，FineBI 做 Array vs CMOS 良率交叉分析
长江存储被制裁后，设备维护靠自研团队 + 国产替代，数据平台断裂 FDL + FineBI 制裁场景下的数据底座重建：制裁导致原厂设备数据接口关闭 → FDL 对接国产设备 SECS/GEM → FineBI 重建良率分析体系。售前话术："制裁之后原厂不维护了，但你们的设备还在跑——FDL 帮你们把国产设备的数据接进来，BI 上良率分析不断档"
国产设备替代（中微刻蚀、北方华创 PVD/CVD）在高深宽比刻蚀仍有挑战 FineBI 国产设备效能对标：FineBI 做国产设备 vs 原厂设备的 MTBF/MTTR 对比分析，量化国产替代的设备效能差距，辅助采购决策

4. 03-半导体设备/行业动态/半导体制造的IT系统：MES、EAP、FDC、SPC与YMS

知识点 帆软产品 售前场景描述
五层系统架构（ERP→MES→EAP→FDC/SPC→设备层），数据格式各不相同 FineDataLink 五层数据打通：FDL 连接 MES（批次数据）、EAP（SECS/GEM 事件）、FDC（毫秒级 Trace Data）、SPC（控制图数据），构建统一数据主题层。售前话术："你们有 5 套系统但数据互相不认识——FDL 是它们之间的翻译官"
MES 由 Applied Materials SmartFactory 或国产（上扬/哥瑞利）主导 FineReport + FineBI MES 之上的分析层：MES 擅长执行不擅长分析。FineReport 在 MES 之上做 WIP 看板、派工效率报表；FineBI 做跨 Lot 的良率对比、设备产能利用率分析
FDC 生成毫秒级传感器 Trace Data，传统单变量阈值误报警多 FineBI + AI Agent FDC 增强分析：FineBI 做多变量 PCA 分析替代单变量阈值，减少 Nuisance Alarm；AI Agent 做 Chamber Matching（跨腔室一致性监控）
YMS 需要关联 5~10 个系统的数据做根因分析 FDL + FineBI 轻量 YMS 替代方案：对于没有 YMS 预算的中型 Fab，FDL 汇聚 MES+SPC+FDC+测试数据 → FineBI 做从晶圆级→Die级→缺陷级的逐级钻取分析

5. 02-封装测试/行业动态/半导体测试技术：CP、FT与ATE体系

知识点 帆软产品 售前场景描述
CP/FT 测试产生海量数据（每片晶圆数千个 Die × 数百项测试参数） FineReport + FineBI 测试报告自动化：FineReport 参数化自动生成 CP Map/Bin Summary/FT 测试报告；FineBI 做跨 Lot/跨机台的测试良率多维对比。售前话术："你们的测试工程师每周花 2 天做 Excel 报表——FineReport 让这些报表自动生成"
ATE 设备由 Advantest/Teradyne 双寡头主导，输出格式差异大 FineDataLink 多 ATE 平台数据统一：FDL 解析 V93000/J750/国产 ATE 的不同输出格式（STDF/ATDF/CSV），统一映射到分析主题层
先进封装需要 KGD（Known Good Die）测试，测试量翻倍 FineReport + FDL KGD 数据链追踪：FDL 从 CP→KGD→封装→FT 全程追踪单颗 Die 的测试结果，FineReport 输出全流程追溯报告——客户稽核时一键导出
