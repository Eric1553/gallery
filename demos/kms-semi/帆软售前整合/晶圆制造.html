🏭 行业画像

晶圆制造（Fab/Foundry）是半导体产业链中资本最密集、技术壁垒最高的环节。一座先进制程晶圆厂投资超 200 亿美元，每天产生数 PB 数据。良率 1% 的波动意味着数千万利润差异。

晶圆厂典型特征： - 高度自动化（数千台设备、数百道工序） - 多系统并存（MES/EAP/SPC/FDC/YMS），数据孤岛严重 - 良率是核心 KPI，质量追溯是客户稽核重点 - 24×7 不间断生产，设备 OEE 直接决定产能

2. 帆软售前引擎/数据分析场景/数据分析-半导体场景矩阵

知识点 帆软产品 售前场景描述
良率数据分散在 MES/EAP/SPC 多个系统，工程师手工汇总 Excel FineReport + FineBI 良率日/周/月报自动化：FineReport 自动生成良率报表 + WIP 看板大屏；FineBI 做良率根因分析（按设备/工艺步骤/班次/材料批次下钻）。售前话术："晶圆厂一个百分点的良率提升价值千万，FineBI 帮工程师从'凭经验调参数'变成'看数据做决策'"
多厂区对标（上海/北京/天津良率不一致） FineReport + FDL 多厂区统一平台：FDL 统一各厂区 MES 数据格式，FineReport 做多厂区良率对标报表。售前话术："为什么北京厂的良率比上海高 2%？FDL 把两个厂的数据拉到一张表上，BI 帮你们找到差异点"
工艺窗口优化 FineBI 工艺参数推荐分析：FineBI 分析历史批次数据，找到良率最优的工艺参数组合（温度/压力/气体流量窗口）

3. 帆软售前引擎/数据底座场景/数据底座-半导体场景矩阵

知识点 帆软产品 售前场景描述
良率数据汇聚（MES+EAP+SPC+YMS → 统一主题层） FineDataLink FDL 五层数据管道：从 MES（批次级）→ EAP（事件级）→ FDC（毫秒级 Trace Data）→ 统一到分析平台。售前话术："你们有 MES 但数据还是靠 Excel 传？FDL 自动把 5 个系统的数据汇聚到一张报表上"
多厂区数据合并 FineDataLink 集团统一数据平台：FDL 做跨厂区数据映射（不同厂可能用不同版本 MES），构建集团级数据底座

4. 帆软售前引擎/AI场景/AI-半导体场景矩阵

知识点 帆软产品 售前场景描述
质量异常预警（制程参数偏离 → 自动告警） AI Agent 实时良率预警：AI Agent 监控 SPC 控制图中的参数漂移，在批量报废前发出告警。售前话术："以前是出了批量问题才发现，现在是参数刚刚漂移就告警"
工艺参数推荐（历史数据 → 最优工艺窗口） AI Agent + FineBI AI 辅助工艺决策：AI Agent 分析 FineBI 中的历史良率数据，推荐最优 Recipe 参数组合
智能问数（自然语言查产能/良率） 智能问数 厂长手机查询："昨天 A 厂区 5nm 良率多少？哪个设备缺陷最多？" → AI 直接回答

5. 01-晶圆制造/行业动态/寒武纪（Cambricon）：中国AI芯片的先驱与挑战

⚠️ 注：寒武纪本质是 Fabless IC 设计公司（存储于 01-晶圆制造 目录），其知识点可同时服务晶圆制造（代工客户）和 IC 设计两个桥接页。

知识点 帆软产品 售前场景描述
寒武纪从 IP 授权转向自研芯片（思元系列），与华为分手后失去最大客户 FineBI 客户依赖度分析：Fab 厂面对客户集中度风险时，FineBI 做客户收入占比/趋势分析。售前话术："你们的客户里，前三大占多少营收？如果最大客户走了，影响多大？FineBI 帮你们量化这个风险"
思元系列芯片 7nm 制程依赖台积电/中芯国际代工 FineReport + FineBI 代工业务视角：晶圆厂用 FineReport 做代工客户（Fabless）的投片量/良率/交付跟踪报表。售前场景：寒武纪这样的 AI 芯片客户投片量波动大、制程要求高 → 晶圆厂需要精准的产能规划和客户分级
BANG 软件栈 vs CUDA 生态差距 — 软件生态是比硬件更大的护城河 FDL + FineBI 研发效能对标：Fab 厂内部也有软件团队（做 YMS、自动化脚本等），FDL+FineBI 帮他们量化软件研发效率，对标行业水平

6. 02-封装测试/行业动态/半导体测试技术：CP、FT与ATE体系

知识点 帆软产品 售前场景描述
CP 测试在晶圆切割前筛出坏 Die，Bin 分类决定芯片最终售价 FineReport + FineBI CP Bin 分析看板：FineReport 生成 CP Map（晶圆图，红绿点显示 Pass/Fail）+ Bin 分布报告；FineBI 做不同产品/批次/机台的 Bin 比例趋势分析。售前场景：一批晶圆 Bin1（最高等级）比例从 70% 降到 50% → 哪个工艺步骤出了问题？
ATE 测试数据格式碎片化（V93000 vs J750 vs 国产 ATE 输出不同） FineDataLink ATE 数据统一：FDL 解析不同 ATE 输出格式（STDF/ATDF）→ FineReport 统一测试报告模板。售前话术："你们有 Advantest 也有 Teradyne，测试数据格式不一样——FDL 帮你们统一"
KGD 测试（先进封装必须每颗 Die 先测试）→ 测试量×2 FineReport + FDL 全流程数据追溯：FDL 从 CP→KGD→封装→FT 追踪单颗 Die，FineReport 一键生成客户稽核报告

7. 01-晶圆制造/行业动态/SPC与良率管理：半导体制造的质量控制体系

知识点 帆软产品 售前场景描述
SPC 控制图（Xbar-R/p/np/c/u 图），人工绘制效率低 FineReport + FineBI SPC 自动生成：FineReport 自动生成标准化控制图（含 Western Electric Rules 判异规则），FineBI 做多变量 SPC 分析（Hotelling T²）。售前话术："你们的质量工程师还在 Excel 里手动画控制图？FineReport 自动生成+自动判异+自动推送告警"
Cp/Cpk 过程能力指数，需区分短期和长期 FineBI 过程能力趋势分析：FineBI 按产品/设备/时间段做 Cpk 趋势，识别过程能力退化的设备
YMS 做从晶圆级→Die级→缺陷级的逐级钻取 FDL + FineBI 轻量 YMS：对于没预算买 PDF Solutions/Synopsys YMS 的 Fab，FDL+FineBI 提供可选替代
