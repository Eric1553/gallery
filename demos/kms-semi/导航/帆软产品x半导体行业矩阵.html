一、📊 数据分析场景（FineReport + FineBI）

晶圆制造 — 良率分析体系

客户痛点： - 晶圆良率直接影响利润，1%良率提升 = 数千万收益 - 良率数据分散在 MES、EAP、SPC 等多个系统 - 工程师需要花大量时间手工汇总报表

FineReport 切入： - 良率日报/周报/月报自动生成 → 替代人工 Excel - 生产看板大屏（WIP、产出、缺陷分布） - 多厂区良率对标报表

FineBI 切入： - 良率根因分析（按设备/工艺步骤/班次/材料批次下钻） - 缺陷帕累托分析和趋势预测 - 工艺窗口优化分析

售前话术： "晶圆厂一个百分点的良率提升价值千万，FineBI 帮工程师从'凭经验调参数'变成'看数据做决策'"

封装测试 — 质量数据管理

客户痛点： - 测试数据量大、格式不统一（不同测试机台输出不同格式） - 质量追溯困难，客户投诉时需要回溯整批数据 - SPC 控制图依赖人工绘制

FineReport 切入： - 自动化测试报告生成（COF/COG报告） - 质量追溯看板（按批次/Lot/客户回溯）

FineBI 切入： - 测试良率多维分析（按产品/封装类型/测试站点） - 异常批次快速定位

半导体设备 — 设备效能分析

客户痛点： - 设备昂贵（一台光刻机上亿），停机损失巨大 - OEE（设备综合效率）手工计算不准确

FineReport 切入： - 设备综合效率（OEE）实时看板 - 设备报警/停机记录报表

FineBI 切入： - 设备MTBF/MTTR趋势分析 - 设备间效能对标分析

二、🗄️ 数据底座场景（FDL + 数仓）

半导体企业的数据孤岛问题

典型现状：

MES系统 ──┐
EAP系统 ──┤
SPC系统 ──┼── 数据互相不通，工程师靠 Excel 手动汇总
ERP系统 ──┤
测试系统 ─┘

FDL 切入价值： - 连接 MES + ERP + WMS + 测试系统，打通数据链 - 构建统一的数据中台/数仓 - 实时同步生产数据到分析平台

售前话术： "你们有 MES 但数据还是靠 Excel 传？FDL 帮你们把 5 个系统的数据自动汇聚到一张报表上"

🎯 售前标准动作流程

见客户前：
  1. 确定客户属于哪个细分领域
  2. 打开对应的「XX-售前场景」页面
  3. 回顾最近该领域的关键动态（每周更新）
  4. 准备 2-3 个同行业客户案例

见客户时：
  1. 用行业洞察开场（显得你很懂半导体）
  2. 指出客户当前的数据痛点（参考本页）
  3. 展示帆软产品的对应解决方案
  4. 用同行业案例佐证

见客户后：
  1. 记录客户反馈和新发现的痛点
  2. 更新客户档案
  3. 补充到售前话术库
