关键设计决策（已定版）
RAGFlow 角色

仅 Ingest：解析 · 切片 · Embedding，写入 Doris。不启用其内置 ES 在线检索。

检索引擎

Doris 为唯一在线检索引擎：BM25 全文索引 + ANN 向量索引并存。

混合融合

双路召回后由 Index API 层做 RRF 融合排序，非单条 SQL 内拼接。

Embedding

bge-large-zh，写入与查询同模型/同版本；归一化向量 + inner_product 近似余弦。

存储索引解耦

OSS 存原文 · Doris 存索引；重建索引不影响 Dora 与 Tool 配置（路线二核心价值）。
