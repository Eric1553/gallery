03 · 文档清单：只改一处，处处生效

清单文件：POC测试执行/01-数据资产/catalog/poc-chunk-profiles.json（当前 v2.0）

里面记录：每个场景有哪些文档、文件名、切片方式、对应附件路径等。其它地方不要重复手写，都从这里读。

谁在用怎么用
演示工作台打开页面时加载清单，展示可入库的文档列表
知识产出页同一份清单，自动生成 SOP 表、经验表
附件接口按清单校验附件是否存在，再提供下载
云上的网页目录运行同步脚本，把 JSON 和 JS 复制到 deploy/web 再上传

新增一篇待入库文档（推荐步骤）

  1. 把 Word/PDF 等文件放到 01-数据资产/attachments/
  2. 在清单 JSON 里，对应场景的 documents 数组加一条记录
  3. 运行 bash deploy/sync_web_from_scene.sh 同步到 deploy/web
  4. 运行 python3 deploy/upload_web_to_ecs.py 上传到云
  5. 若有新附件文件，再运行 python3 deploy/upload_data_assets_to_ecs.py
  6. 在工作台点「加载附件」→「场景一键入库」
  7. （场景三）若与故障码有关，按需改 service-fault-graph.json
  8. （Dora）按需改 03-Dora-Agent/.../02-knowledge-rules.txt 里的问答路由说明
不会跟着清单自动变的：故障图谱里的跳转关系、Dora 里的业务话术、验收用的标准答案 JSON——这些需要人工改对应文件。

05 · 文档怎么搜、怎么说明「搜的过程」

场景一、三的「问制度/问手册」，底层都是：先把问题变成向量，再在 Doris 里做关键词 + 语义两路检索，合并后返回最相关的段落。

功能接口 / 工具名说明
普通检索 POST /api/v1/retrieve 输入问题，返回最相关的文档片段列表
带过程说明的检索 POST /api/v1/retrieve/explain 除结果外，还返回：筛了哪个场景、两路各命中什么、怎么合并、一段中文摘要说明
场景一 Agent 工具 finance_policy_retrieve_trace Dora 调财务检索时，可一并拿到上述过程说明
场景三 Agent 工具 service_manual_retrieve_trace Dora 调售后手册检索时，同上

建议在 Dora 规则里要求：需要引用文档时，回答里附带「检索说明」，方便验收时核对依据。

08 · 改完代码后怎么发布、怎么自测

常用命令

# 1. 把前端页面和文档清单复制到 deploy/web

# 2. 上传到云上的网页目录
python3 deploy/upload_web_to_ecs.py

# 3. 上传附件和清单到云上的 Worker 目录（有新文件时）
python3 deploy/upload_data_assets_to_ecs.py

python3 deploy/upload_worker_to_ecs.py
python3 deploy/upload_mcp_to_ecs.py
