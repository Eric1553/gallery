## 3. 新功能详解

### 3.1 🎯 一键弹药 — 客户速览包 (A4)

**功能描述:** 输入客户名（如"北方华创"/"台积电"/"TCL"）→ 自动聚合5组弹药卡片

**弹药包结构:**
```
a. 📋 行业框架（1-3条）  — 客户所属行业的财务/技术框架
b. 🏢 企业档案（1-2条）  — 客户深度企业档案
c. 🎯 匹配产品方案（3-5条）— FineReport/FineBI/FDL/简道云可解决场景
d. 📊 类似标杆案例（2-3条）— 同行业成功案例
e. ⚡ 竞品动态（1-2条）   — 相关竞品信息
```

**预设客户:** 台积电、北方华创、中芯国际、TCL、ASML、长江存储、长鑫存储、比亚迪半导体、华虹半导体、上海微电子、NVIDIA、三星

**交互特性:**
- 弹药卡片组折叠/展开
- 一键复制整个弹药包为Markdown
- 支持模糊客户名（通过aliases映射）

**实现方式:**
- `customerAmmoMap` — 客户×关键词映射表（嵌入JS）
- `generateAmmoPack()` — 按5组规则聚合allItems数据
- `window.copyAmmoPack()` — 生成Markdown并复制

### 3.2 🧠 产品-场景智能匹配 (A5)

**功能描述:** 支持自然语言查询 "FineReport能在封测做什么" → 自动识别产品名+领域 → 匹配场景方案

**产品×场景映射表 (productSceneMap):**
- FineReport → 晶圆制造/封测/设备/IC设计/财务
- FineBI → 同上（侧重分析型场景）
- FineDataLink → 数据集成场景
- 简道云 → 零代码流程场景
- AI Agent → AI/预测/预警场景

**匹配结果标记:**
- 🟢直接匹配 — 查询中产品名+领域都命中
- 🟡相关参考 — 产品名命中但领域不完全匹配

### 3.3 模式切换

**搜索模式:** 传统关键词搜索（保留v3所有功能）
**弹药模式:** 客户速览包输入区（专为售前见客户前快速准备设计）

切换通过URL hash的`mode`参数持久化。

### 3.4 关键数据提取 (A6)

搜索时自动提取12组关键数据点（如"中国半导体自给率约17%"），展示在搜索结果上方的banner中。

### 3.5 搜索建议自动补全

输入时动态显示匹配的标题/标签建议（最多8条），支持↓↑选择、Enter填入。

### 3.6 热门搜索动态化

基于localStorage统计真实搜索频率，动态调整热门搜索排序（高频词自动🔥标记）。

### 3.7 时效性标记

自动提取标题/描述中的年份，在卡片中显示📅2025/📅2026标签。

### 3.8 URL持久化增强 (A9)

新增`page`参数保存分页位置，刷新后恢复到之前的分页。
