管理痛点
  • 合见大量订单经借测后转销售，铺货与转化难追踪；
  • 在借超期、借转销停滞缺乏预警与督办；
  • 「卖→借→转/还→收」全链路未打通，收入实现滞后；
  • 转化驱动因素（客户/产品/时长）难量化。
管理目标
提升「借测铺货 → 借转销 → 回款」闭环效率
铺货可追踪
转化可提升
超期可督办
收入可预期
保障措施
  • 销售驾驶舱：漏斗 / 铺货热力 / 借转销；
  • 借测生命周期专题：在借天数 / 超期督办；
  • 借转销回款归因：驱动因素 + 账龄；
  • 财务驾驶舱：收入成本 / DF / 回款映射。
