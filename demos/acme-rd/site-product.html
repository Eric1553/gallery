Site 与产品管理

立项 · 机台 · Spec · Recipe/WPH · 文档

1
立项管理
①不同 Site 立项项目数：取 OA 项目立项流程（客户名称）；②不同产品类别立项数：取 OA 项目启动流程；按成熟 / 量产 / 研发机台分类。Site 约 100+，采用 Top N 排名 + 筛选框，并提供二级明细列表页。
2
机台状态
从 CRM 展示各客户（Site）/ 产品类型的机台数量及装机进度，状态包括 Pre Setup / T0 / T1 / T2 / T3 / RLS 等，支持按月 / 年筛选。
3
Layer RLS 状况
按Site 展示 Layer Release 状况，对标 POR 机台数量；可下钻至每个机台具体 Step 的 RLS 情况（Application 维度）。数据来源 CRM。
4
Spec 风险前置
统计 Spec 风险前置流程发起数占 Spec 总流程（含 Spec 新增变更）比例；展示验证中 / 已归档 / 进行中；计算发起至归档耗时；按 Site 分布。
5
Recipe / WPH
按 IC1~IC4 组别切换，在各 Site 维度展示：Recipe—上传数量、上传完成度、健康度（均值）、修改完成度、入档率；WPH—上传数量、完成度、健康度（排除空值后取均值）。
6
标准化文件 / 产品文档 / 公司级 Fanout
标准化文件需求 / 发布：流程总数、已归档、入档率。产品文档：必传附件完成度，支持按阶段（T1 / T2 / T3 / RLS）、按项目 / Site 筛选。公司级 Fanout：申请发布（公司内/外、工艺/软件/安全/质量/硬件、产品类别关联经理）→ 区域经理选机台 → Site Manager 执行反馈 → 项目经理 / 工艺产品经理 / 设备产品经理定期汇总。
7
更新动态
统计各产品 Case 更新数量、标准化文件更新、Case 流程内结案报告上传数（一流程有文件算 1 次），支持周更新与累计。
