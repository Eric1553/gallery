OA 流程监控

节点耗时 · 超时预警 · 关键节点 GAP 控制

当前展示 11 类流程（含 RD 研发需求申请），完整清单待业务确认。
1
通用流程监控
覆盖 Checksheet / Spec / Case / 标准化文件发布 / 产品文档 / Spec 风险 / 标准化文件新增变更 / 人力支援 / 技能评定等流程。展示节点 / 部门（顶级）/ 人员耗时；HL 耗时最长部门与人员排名；人员 Hold 节点情况（人员 + 已耗时 + Hold 流程条数，每周三更新）；所有流程归档率（可钻取）；超时人员排名（定位到人）；个人流程平均耗时（可推送推送）；并行节点以最后审批时间计算总耗时。
2
Checksheet 关键节点控制
Checksheet 需求时间、提交 Due Date、实际提交时间（PE Owner 首次审批）、GAP；及时提交率 = GAP 为 0 的流程占有 GAP 数据流程总数的比例；GAP 大于 7 天（不含节假日）高亮，附流程链接。
3
Spec 入档控制（联动项目启动）
项目启动流程（18 节点）与 Spec 新增流程入档时间 GAP，小于 7 天为及时；及时入档率 = GAP 小于 7 天流程数 ÷ 总流程数；HL 出超标准入档时间的流程，含申请人、流程链接、流程中耗时最长人员及部门。
4
标准化文件评审控制
标准化文件发布流程：需求评审计划时间 vs 实际开会时间 GAP（GAP ≤ 0 按时）、及时完成率、归档率，按产品 × 文件类型统计数量 / 归档数 / 归档率。标准化文件新增变更需求流程：需求完成 plan vs 实际提交 GAP、承接人 plan vs 实际提交 GAP。
5
产品文档归档控制
产品文档归档率；按Site 产品总归档耗时；按IC1-4 组各节点耗时；按申请人所在组维度分析。
+
Spec 风险 → 项目需求导入
补充耗时监控：Spec 风险前置触发后的「项目需求导入」流程链路（触发数、导入完成率、节点耗时、未闭环清单）。与 Site 看板 Spec 风险 Tab 联动。
!
个人提醒与说明
个人流程耗时可定时推送（群通知 / 邮件）；超时提醒次数按 OA 推送记录统计。
